# drahmadimanesh-
Coaching App Development — ساخت اپلیکیشن برای کوچینگ
معجزه ذهن — PWA prototype v1
نمونه اولیه فارسی و واکنش‌گرا برای برند آموزشی: صفحه اصلی، دوره‌ها، کتابخانه، کوچ‌ها، فرم درخواست مشاوره، کیف پول نمایشی، تاریخچه نمایشی و فهرست پذیرندگان نمونه.
فایل‌ها
index.html: رابط کاربری و تعاملات اولیه
manifest.webmanifest: تنظیمات PWA
sw.js: کش فایل‌های اصلی برای بازشدن پایه‌ای آفلاین
icon.svg: آیکون
اجرای محلی
فایل index.html را باز کنید تا ظاهر و تعاملات نمایشی را ببینید. برای نصب PWA و فعال‌شدن Service Worker، فایل‌ها باید روی HTTPS یا localhost اجرا شوند.
انتشار رایگان آزمایشی با GitHub Pages
در GitHub یک repository عمومی جدید بسازید.
فایل‌های این پوشه را در ریشه repository بارگذاری کنید.
در Settings → Pages، گزینه Deploy from a branch را انتخاب کنید و branch اصلی و پوشه / (root) را تنظیم کنید.
پس از انتشار، لینک Pages را از گوشی باز کنید و از منوی مرورگر Add to Home Screen را انتخاب کنید.
توجه: GitHub Pages فقط برای دموی استاتیک است و برای کاربران داخل ایران تضمین دسترسی بدون VPN ندارد. برای هدف نهایی باید میزبانی داخلی را از چند اینترنت ایرانی آزمایش کنیم.
محدودیت‌های مهم
نام دوره‌ها، کوچ‌ها، کتاب‌های نمونه، پذیرندگان و قیمت‌ها فرضی‌اند و باید با تأیید مالک برند جایگزین شوند.
کیف پول، شارژ و پرداخت فقط نمایشی است؛ هیچ پول واقعی جابه‌جا نمی‌شود.
فرم مشاوره و درخواست‌ها به سرور ارسال نمی‌شوند.
برای محصول واقعی نیاز به بک‌اند امن، احراز هویت، پایگاه داده، ثبت سروری دفترکل تراکنش، کنترل دسترسی پذیرنده، جلوگیری از پرداخت تکراری و اتصال روش پرداخت معتبر داریم.
اطلاعات مالی و حساب کاربری را به localStorage به‌عنوان منبع قابل اعتماد نسپارید.
